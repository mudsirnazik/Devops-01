📝 PHASE 4: Create Dockerfiles for TaskBloom

Backend Dockerfile (./backend/Dockerfile)

FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
EXPOSE 5000
CMD ["node", "server.js"]

Frontend Dockerfile (./frontend/Dockerfile)

FROM node:18-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /app/build /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

Docker Compose (docker-compose.yml)

version: '3.8'
services:
  backend:
    build: ./backend
    ports:
      - "5000:5000"
    environment:
      - NODE_ENV=production
    restart: always

  frontend:
    build: ./frontend
    ports:
      - "3000:80"
    depends_on:
      - backend
    restart: always

🚀 PHASE 5: Jenkins Pipeline (Production Ready)

Jenkinsfile (Create in GitHub root)

pipeline {
    agent any
    
    environment {
        DOCKER_IMAGE_BACKEND = 'taskbloom-backend'
        DOCKER_IMAGE_FRONTEND = 'taskbloom-frontend'
    }
    
    stages {
        stage('📦 Checkout Code') {
            steps {
                git branch: 'main', 
                    url: 'https://github.com/your-username/taskbloom.git'
                echo 'Code cloned successfully!'
            }
        }
        
        stage('🐳 Build Backend Image') {
            steps {
                script {
                    docker.build("${DOCKER_IMAGE_BACKEND}:latest", "./backend")
                    echo 'Backend image built!'
                }
            }
        }
        
        stage('🐳 Build Frontend Image') {
            steps {
                script {
                    docker.build("${DOCKER_IMAGE_FRONTEND}:latest", "./frontend")
                    echo 'Frontend image built!'
                }
            }
        }
        
        stage('🛑 Stop Old Containers') {
            steps {
                script {
                    sh 'docker stop taskbloom-backend || true'
                    sh 'docker stop taskbloom-frontend || true'
                    sh 'docker rm taskbloom-backend || true'
                    sh 'docker rm taskbloom-frontend || true'
                }
            }
        }
        
        stage('🚀 Run Containers') {
            steps {
                script {
                    sh '''
                        docker run -d --name taskbloom-backend -p 5000:5000 taskbloom-backend:latest
                        docker run -d --name taskbloom-frontend -p 3000:80 taskbloom-frontend:latest
                    '''
                    echo '✅ Application deployed successfully!'
                }
            }
        }
        
        stage('🔍 Health Check') {
            steps {
                script {
                    sh 'sleep 5'
                    sh 'curl -f http://localhost:5000/health || exit 1'
                    echo '✅ Health check passed!'
                }
            }
        }
    }
    
    post {
        success {
            echo '🎉 Deployment Successful!'
            echo 'Frontend: http://' + env.NODE_NAME + ':3000'
            echo 'Backend API: http://' + env.NODE_NAME + ':5000'
        }
        failure {
            echo '❌ Deployment Failed! Check logs.'
        }
    }
}
✅ Jenkins Pipeline will auto-deploy on every git push!

☸️ PHASE 6: Kubernetes Setup (Production Grade)

Option A: Minikube (Local Testing)

curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube
minikube start --driver=docker

Option B: Kind (Kubernetes in Docker) - Recommended

curl -Lo ./kind https://kind.sigs.k8s.io/dl/latest/kind-linux-amd64
chmod +x ./kind
sudo mv ./kind /usr/local/bin/kind
kind create cluster --name taskbloom

Kubernetes Deployment YAML (backend.yaml)

apiVersion: apps/v1
kind: Deployment
metadata:
  name: taskbloom-backend
  namespace: default
spec:
  replicas: 2
  selector:
    matchLabels:
      app: backend
  template:
    metadata:
      labels:
        app: backend
    spec:
      containers:
      - name: backend
        image: taskbloom-backend:latest
        imagePullPolicy: IfNotPresent
        ports:
        - containerPort: 5000
---
apiVersion: v1
kind: Service
metadata:
  name: backend-service
spec:
  selector:
    app: backend
  ports:
    - port: 5000
      targetPort: 5000
  type: ClusterIP
kubectl apply -f backend.yaml
kubectl get pods
kubectl get svc

🔧 Common Issues & Solutions

Issue: Jenkins Docker permission denied
Solution: sudo usermod -aG docker jenkins && sudo systemctl restart jenkins
Issue: Port already in use
Solution: sudo lsof -i :3000 && kill -9 PID
Issue: Kubernetes pods stuck in CrashLoopBackOff
Solution: kubectl logs pod-name && check image name
